# SOP — Prosedur Baku Operasional (Infarm 360° Portal)

Kumpulan **prosedur langkah-demi-langkah** untuk kejadian berulang yang rawan salah atau butuh
jejak akuntabilitas. Ditujukan untuk **tim HRD** (dan sebagian menyinggung SPV/Koordinator).
Ringkas & bisa diserahkan/dicetak. Terminologi mengikuti **`PANDUAN Infarm 360 Portal.pdf`** dan
panduan pengguna **[../CARA-PENGGUNAAN.md](../CARA-PENGGUNAAN.md)**.

> Prinsip yang mendasari semua SOP: aplikasi **menegakkan kebijakan & integritas** (RLS, wajib
> komentar audit, gate periode/360°), **bukan** menambal kelalaian individu. Ikuti langkahnya; jejak
> perubahan tercatat otomatis di **Log Aktivitas HRD**.
